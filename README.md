# うちの近くマップ（新潟市版）

新潟市のオープンデータを使い、自宅周辺の避難場所などを地図で確認できる静的Webサイトです。
目玉機能は、**災害の種類（津波・洪水など）で避難場所を絞り込む**ことです。

> この地図は参考情報です。避難時は必ず新潟市の公式ハザードマップ・避難情報を確認してください。
> 個人が作成した非公式サイトで、新潟市が作成・保証したものではありません。

## 構成

- 静的サイト（Vite + MapLibre GL JS、国土地理院タイル）。サーバー不要で GitHub Pages に公開できます。
- `scripts/fetch.py` … 新潟市のCSVを取得（`data/raw/`、取得日は `data/raw/fetch-log.json`）
- `scripts/convert.py` … CSV → GeoJSON（`public/data/`）。再実行しても同じ結果になります。
- `scripts/sources.py` … 取り込むデータの定義（URL・列）
- `src/` … 画面。`docs/data-report.md` … 段階1のデータ調査、`docs/convert-log.md` … 変換ログ

## 使い方

```sh
npm install
python3 scripts/fetch.py     # 任意: CSVを再取得
python3 scripts/convert.py   # GeoJSON を再生成
npm test                     # 変換のテスト
npm run dev                  # 開発サーバー
npm run build                # dist/ に出力
```

## 扱いの決め事

- 主データは「指定緊急避難場所一覧」。屋内避難所・屋外避難場所のデータにあり、一覧に見当たらない施設は「(A)未収録」として別に表示します（災害種別の情報がないため、絞り込み中は非表示）。
- 津波避難ビルは、一覧と同じ施設（名称一致かつ200m以内、または50m以内）は一覧側に情報を追加し、一覧に無いものだけ別レイヤーにしています。
- 災害種別の値: `○`=対応あり、`2階以上`等=階数・場所の条件つき（元の文言を表示）、`×`・`－`=不明（市の説明で意味を確認できていないため。元の値を併記）、空欄=データなし。未知の値が出たら変換が失敗します。
- 座標系は日本測地系2000（緯度・経度）と記載されています。国土地理院タイルとは市域の規模ではほぼ同一として扱っています。
- 入力した住所は国土地理院の住所検索APIに送られます。位置情報は端末内で処理し、当サイトには送信・保存しません。

## データの更新

GitHub Actions（`.github/workflows/update-data.yml`）が週1回、CSVを再取得して差分があれば PR を作ります。
取得失敗、列名の変更、災害種別の新しい値が出た場合は PR を作らず Issue で通知します。

## スマホでの動作確認

1. `npm run build && npm run preview` を実行し、同じ Wi-Fi のスマホから表示するか、公開後のURLを開く。
2. 幅360px前後で次を確認する: 津波・洪水のチップで件数が変わる／ピンを置くと「最も近い避難場所」が出る／ポップアップに災害種別の表が出る／下タブで地図に戻れる／「この表示の見かた」が開く。
3. iPhone Safari と Android Chrome の両方で確認する。
