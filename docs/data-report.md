### 意味の確認状況
**確認できたこと**
- 国の定義書A（自治体標準オープンデータセット、2026-08-01版）には、災害種別列は「指定緊急避難場所における対応災害種別について、状況を以下の中から記載」とあり、選択肢は「対応済み」「未対応」。「指定避難所との重複」は「重複している」。

**確認できなかったこと（推測しない）**
- `○` `×` `－` 空欄、階数条件（`2階以上` `3階以上` `4階以上` `全階可` `体育館`）が新潟市で何を意味するか。定義書には記載がなく、新潟市の公式説明は今回の調査では見つけられなかった（防災ページのURLは404。ハザードマップ・避難所案内ページでの確認が残る）。
- 特に `×` と `－` の違い、`全階可` が「浸水想定に関係なくどの階でも」の意味かどうか。

### 正規化ルール案
| 元の値 | 正規化 | 画面表示 |
|---|---|---|
| `○` | 対応あり（定義書の「対応済み」に相当すると想定。ただし新潟市での明示は未確認） | 元の値も併記 |
| `2階以上` `3階以上` `4階以上` `全階可` `体育館` | 階数条件つきで対応（条件の文言をそのまま表示。解釈は付けない） | バッジ表示 |
| `×` | 不明（未確認のため。「対応なし」と断定しない） | 元の値 `×` を表示 |
| `－` | 不明 | 元の値 `－` を表示 |
